What to include in your support request

  • Apple TV model (HD or 4K, generation if known)
  • tvOS version (Settings → About → tvOS version)
  • App version (shown in About & Support in the app)
  • Whether you used Browser Import or manual entry
  • Your VPN provider or whether you're self-hosting
  • Any on-screen tunnel log entries (from the Tunnel Log screen)
  • A clear description of the issue and steps to reproduce

Common issues

Browser Import doesn't work

Make sure both devices are on the same local network. Some routers have "client isolation" or "AP isolation" enabled, which prevents devices from communicating with each other. Check your router settings. Also ensure the browser has Local Network permission on iOS/macOS (Settings → Privacy → Local Network).

VPN won't connect

Verify your configuration works with another WireGuard client first. Check the Tunnel Log in the app for error messages. If you're using a provider that requires a username and password (rather than a key-based config), that provider likely uses OpenVPN, which is not yet supported (Good thing we have a free trial, huh?).

The app says "Trial expired" but I already purchased

Use the "Restore Purchases" button on the paywall screen. If that doesn't work, ensure you're signed in to the same Apple Account that made the purchase.
