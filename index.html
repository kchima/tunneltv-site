Frequently Asked Questions

Does TunnelTV include a VPN service?

No. TunnelTV is a client that connects to your existing WireGuard configuration from a provider or your own server. You bring the config.

What do I need to use it?

An Apple TV (HD or 4K) running tvOS 17 or later, and a standard WireGuard wg-quick configuration file.

How do I import a configuration?

Open the app, choose "Import from Browser," then open the displayed URL on any device on the same network. Enter the PIN shown on your TV, paste your config, and save. You can also enter configuration fields manually.

Is browser import secure?

The import page is served over plain HTTP on your local network, only while the Import screen is open. A one-time PIN (shown on the TV) and a Host-header check prevent unauthorized submissions. Do not use Browser Import on an untrusted network such as public Wi-Fi, hotels, or cafes.

Why does Apple TV ask to add a VPN configuration?

tvOS requires permission before a VPN tunnel can be created. This is a standard system prompt — approve it once per tunnel.

What does "Disconnect on stale handshake" do?

When enabled, the app disconnects if a previously-working WireGuard peer stops responding. This is not a traffic-blocking kill switch — normal routing may resume after the disconnect.

How does the trial work?

You get 3 days of full access starting from first launch. After that, the app requires a one-time $19.99 purchase. Restore Purchases is available if you've already bought the app on another device.

What should I include in a support email?

Your Apple TV model, tvOS version, app version, whether you used Browser Import or manual entry, and a description of the issue. If you have the on-screen tunnel log, include it — but never email a private key or full configuration file.
